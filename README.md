# Лабораторная работа 4. Основы JavaScript

**Выполнил:** Агнещиков Артём вариант 9

## Описание
Интерактивный скрипт на языке JavaScript на тему Музыкант и звукорежиссёр
Реализованы базовые алгоритмы обработки числовых массивов функции циклы и условные конструкции
Скрипт интегрирован в существующий макет сайта визитки

## Выполненные требования задания
В коде реализованы все обязательные элементы и требования Варианта 9
* Ввод и вывод данных
    Ввод имени пользователя через диалоговое окно prompt с обработкой пустой строки
    Вывод приветствия средней громкости и числа громких треков через alert
    Вывод статистики по тихим трекам и сервисных предупреждений в консоль
* Функции обработки массивов
    Функция подсчёта суммы элементов массива
    Функция поиска максимального значения в массиве
    Функция фильтрации громких треков со значением выше 90 дБ
* Циклы и логические условия
    Цикл для перебора массива подсчёта количества и средней громкости тихих треков до 75 дБ
    Условная проверка выводящая предупреждение в консоль при пиковой громкости от 105 дБ
* Дополнительный функционал
    Добавлен скрипт управления аудиоплеерами страницы для предотвращения одновременного звучания треков

## Как запустить
Откройте файл `index.html` в любом браузере. Убедитесь, что:
1. Файл `script.js` находится в одной папке с `index.html`
2. Файл `style.css` и папка `files` находятся в том же каталоге
3. Для просмотра подробного вывода откройте консоль браузера (клавиша F12 или Ctrl+Shift+I)
