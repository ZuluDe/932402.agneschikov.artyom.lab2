# Лабораторная работа 2. Базовые и продвинутые возможности CSS

**Выполнил:** Агнещиков Артём вариант 9

## Описание
Одностраничный сайт-визитка на тему "Музыкант и звукорежиссёр". В данной работе HTML-разметка отделена от визуального оформления, а также внедрены продвинутые возможности CSS: переменные, позиционирование, интерактивные состояния элементов и CSS анимации. Дизайн выполнен в тёмной теме с фиолетовыми акцентами.

## Выполненные требования задания
В коде реализованы все обязательные элементы и требования Варианта 9:
* **Способы подключения CSS:** 
  * Основной стиль вынесен во внешний файл `style.css`
  * Добавлено 1 правило во внутреннем блоке `<style>`
  * Применён 1 `inline` стиль - свойство `display: flex` для контейнера формы обратной связи
* **CSS-переменные:** 
  * В псевдоклассе `:root` заданы переменные для основной палитры и шрифтов
* **Примеры позиционирования:** 
  * `static` явно задано для `body`
  * `relative` применено к пунктам списка проектов - контейнер для эквалайзера
  * `absolute` использовано для позиционирования звуковых волн относительно треков
* **Состояния элементов:** 
  * `:hover` подсветка ссылок в навигации и запуск анимации волн при наведении на проект
  * `:active` эффект уменьшение масштаба кнопки отправки формы
  * `:focus` появление светлой рамки вокруг полей `input` и `textarea` при вводе текста
  * `:visited` изменение цвета для уже посещённых ссылок в меню
* **Индивидуальное задание:**
  * С помощью псевдоэлементов `::before` и `::after` созданы визуальные волны рядом с названиями проектов
  * Реализована кастомная анимация дрожания `@keyframes shake` при наведении на волны
* **Общие требования доступности:** 
  * Контрастность текста и фона составляет не менее 4.5:1
  * Добавлены аудиоплееры `<audio>` с инверсией цвета под тёмную тему и обложки треков со сглаженными углами. У `textarea` заблокировано изменение размеров `resize: none`

## Как запустить
Откройте файл `index.html` в любом браузере. Убедитесь, что:
1. Файл `style.css` находится в одной папке с `index.html`
2. Папка `files` со всем содержимым находится в том же каталоге
