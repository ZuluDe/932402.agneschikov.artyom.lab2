# Лабораторная работа 1. Основы HTML и структура веб-страницы

**Выполнил:** Агнещиков Артём вариант 13

## Описание
Одностраничный сайт-визитка на тему "Волонтёр и социальный активист". Демонстрирует базовые навыки семантической разметки страницы. Текстовое наполнение выполнено в сатирическом ключе

## Выполненные требования задания
В коде реализованы все обязательные элементы:
* **Структура HTML5:** 
  * `<header>` шапка с именем и заголовком;
  * `<main>` контейнер для основного контента;
  * `<section>` секция «Навыки» - маркированный список `<ul>` и секция «Проекты» - нумерованный список `<ol>`;
  * `<aside>` боковая панель с информацией о социальной проблеме;
  * `<footer>` подвал с копирайтом и годом;
* **Медиа:** 
  * Добавлено изображение `<img>` со всеми обязательными атрибутами: `src`, `alt`, `width` и `height`
* **Форма обратной связи:** 
  * Реализованы поля «Имя» `type="text"`, «Email» `type="email"` и «Сообщение» `<textarea>`
  * У всех полей прописаны атрибуты `name` и `placeholder`
  * Добавлена кнопка отправки данных
* **CSS3:** базовая стилизация страницы в заданной красно-белой гамме.

## Как запустить
Откройте файл `index.html` в любом браузере. Убедитесь, что папка `files` с изображением `avatar.jpg` находится в том же каталоге.
