# Лабораторная работа 3. Вёрстка макета с помощью Flexbox и Grid

**Выполнил:** Агнещиков Артём вариант 9

## Описание
Одностраничный сайт визитка на тему Музыкант и звукорежиссёр
Внедрены Flexbox для одномерных макетов и CSS Grid для двумерных а также принципы адаптивной вёрстки
Дизайн выполнен в тёмной теме с фиолетовыми акцентами

## Выполненные требования задания
В коде реализованы все обязательные элементы и требования Варианта 9
* Вёрстка Flexbox
    Навигационное меню сделано горизонтальным и адаптивным
    Секция Мои релизы использует Flex карточки для вывода типа релиза года жанра и обложки
* Вёрстка Grid
    Создан дашборд Студийное оборудование с сеткой из двух строк по три блока
    Каждый блок содержит фото устройства название и назначение
* Адаптивность и медиа запросы
    Для мобильных экранов карточки релизов и Grid галерея выстраиваются в 1 колонку
    На планшетах карточки и оборудование перестраиваются в 2 колонки
    На десктопе карточки релизов выстраиваются в 4 колонки а Grid сетка оборудования в 3 колонки
    Обеспечено отсутствие горизонтальной прокрутки при любых размерах экрана
* Семантика и доступность
    Для указания года релиза внедрен семантический тег time с атрибутом datetime
    Обеспечена контрастность текста и фона со значением не менее 4,5 к 1
    Для карточек применены семантически верные HTML теги

## Как запустить
Откройте файл `index.html` в любом браузере. Убедитесь, что:
1. Файл `style.css` находится в одной папке с `index.html`
2. Папка `files` со всем содержимым находится в том же каталоге
